# Page code served to ncsoccer.org

Each file here is the full code for one ncsoccer.org page. The page itself holds only a small
loader block that fetches the file from this folder, so a page is updated by changing its file
here; no WordPress edit is needed.

- `ncysa-calendar.html` — NCYSA Calendar & Events (www.ncsoccer.org/ncysa-calendar/)
